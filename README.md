# Nusaiba Ahmed — Digital Portfolio

This is a simple static digital portfolio built with HTML, CSS, and JavaScript.
It can be deployed for free using GitHub Pages.

## Sections

- About
- Skills
- Projects
- Experience
- Education
- Publication
- Contact

## How to run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## How to deploy on GitHub Pages

### Option 1: User site

Create a repository named:

```bash
nusaibaahmed4871-lgtm.github.io
```

Then push this project to that repo. It will be available at:

```text
https://nusaibaahmed4871-lgtm.github.io
```

### Option 2: Project site

Create a repository named:

```bash
digital-portfolio
```

Push the files, then go to GitHub:

Settings → Pages → Deploy from branch → main → root

## Privacy note

The public portfolio intentionally uses only email, LinkedIn, GitHub, and city-level location.
Full home address and phone number are not shown for safety.
